features:
  - title: One place to write
    details: Notifications live in a Notifications App. Fill it from an Excel file, a QVD or any data source your load script can read.
  - title: Reaches the right apps
    details: Target a Channel such as sales, every app with all, or specific app IDs. Notifications start and stop on their own.
  - title: Stays inside Qlik
    details: Reads with the Viewer's own login. No external service, no web integration and no tenant security-policy (CSP) changes.
  - title: Built to Qlik's guidelines
    details: A nebula.js extension with plain text or basic Markdown, four Severities, Dismissal, theme-aware styling and screen reader support.
